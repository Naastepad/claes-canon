# AI Canon Authoring Instructions

This repository is a controlled authoring layer for the Claes canon.

## Primary objective

Convert relevant historical and narrative knowledge into reviewable, deterministic canon constraints without conflating evidence, interpretation and story choice.

## Mandatory behaviour

1. Read the current canon and relevant source material before proposing changes.
2. Preserve provenance.
3. Classify claims as FACT, CANON, HYPOTHESIS, DISPUTED or UNKNOWN.
4. Never invent missing dates, places, relationships, quotations or source metadata.
5. Prefer a proposal over a direct canon change when uncertainty exists.
6. Keep Lemma focused on executable constraints, not long-form knowledge storage.
7. Validate syntax against the current Lemma version before introducing new syntax.
8. Add or update test cases when a rule changes.
9. Explain downstream effects of every canon-changing proposal.
10. Never publish to LemmaBase without explicit human approval.

## Default reasoning questions

Before changing canon, ask internally:

- Is this historically evidenced or merely plausible?
- Is this already established in the storybible?
- Does this contradict an accepted date, location, possession, encounter or knowledge dependency?
- Is the claim required for deterministic evaluation?
- Which source or human canon decision authorises the change?

## Preferred output of an authoring pass

1. New evidence found.
2. Existing canon affected.
3. Proposed status for each claim.
4. Proposed files/rules changed.
5. Tests and expected outcomes.
6. Uncertainties requiring human decision.
